# 12 шагов — офлайн-дневник для Android

## Запуск веб-приложения на Linux

Веб-приложение с 12 интерактивными модулями находится в [ветке `main`](https://github.com/Nodensss/12SHAGOV/tree/main). Для запуска на Linux достаточно Python 3:

```bash
git clone --branch main --single-branch https://github.com/Nodensss/12SHAGOV.git 12SHAGOV-linux
cd 12SHAGOV-linux
python3 -m http.server 4173 --bind 127.0.0.1 --directory public
```

Откройте <http://localhost:4173>. Текущая ветка содержит Android-проект с отдельными командами ниже.

Если репозиторий уже клонирован, выполните в его каталоге `git fetch origin main:refs/remotes/origin/main`, затем `git switch main` и команду Python выше. При установленном Node.js 22+ вместо неё можно выполнить `npm start`.

Приложение, чтобы идти по 12 шагам в своём темпе: к каждому шагу — краткий пересказ,
что может помочь, чем может обернуться, «здоровое прочтение», опыт участников и вопросы
для размышления с полями для ответов. Всё наполнение взято из исследования
[`docs/issledovanie.md`](docs/issledovanie.md) («12 шагов АН: польза, критика и опыт участников», 31.10.2026).

Работает без интернета, записи хранятся только на телефоне.

> Это не официальное приложение АН и не официальный текст шагов (описания — пересказ).
> Это не лечение и не замена врачу. При угрозе жизни — **112**.

## Добавление своих оригиналов в Первый шаг

Открой **Шаг 1 → Загрузить материалы в шаг**. После разблокировки Тетради
добавь книги (PDF/EPUB/TXT/MD), формулировку шага или вопросы (TXT/MD).
Предпросмотр показывает, что будет сохранено. Книги появятся в Источниках,
вопросы — в Тетради. Всё работает на устройстве без пересборки APK.
Подробно: [Как загрузить материалы](docs/MATERIALS.md).

### Вступление

При запуске показывается заставка (~24 секунды): касание экрана открывает книгу — с этого касания
начинается и звук (браузеры и Android не дают играть звук без действия пользователя).
Сверху есть кнопки «Звук» и «Пропустить». В «Ещё → Вступление» можно посмотреть его снова,
отключить показ при запуске и выключить звук.

- Картинка нарисована в SVG/CSS (`www/js/intro.js`, `www/css/intro.css`), огонь и искры — на canvas.
  Чужие изображения не используются.
- Звук — Web Audio: низкий гул, треск огня, шелест страниц, хор (ре минор → си-бемоль → ля → ре мажор),
  пульс барабана и удар с гонгом на названии. Микс рассчитан и на динамик телефона: основная энергия выше 250 Гц.
- Шрифты Cormorant Garamond и Cormorant SC (лицензия SIL OFL, `www/fonts/OFL-Cormorant.txt`) лежат в приложении —
  интернет не нужен.
- Короткая вибрация при раскрытии книги и на финальном ударе (разрешение `VIBRATE`, запрашивать не нужно).
- При системной настройке «Уменьшить движение» камера не двигается и частиц меньше.
- Тексты строк и названия — в начале `www/js/intro.js` (`LINES`, `TITLE`, `SUBTITLE`).

## Как поставить на Android

### Вариант 1. Готовый APK (проще всего)

1. Скачайте файл `12-shagov.apk` на телефон (из GitHub Actions — см. вариант 2 — или из релиза).
2. Откройте его. Android попросит разрешить установку из этого источника
   (браузер / «Файлы» / Telegram) → **Настройки → Разрешить из этого источника** → назад → **Установить**.
3. Если Google Play Protect предупредит о неизвестном разработчике — **Подробнее → Всё равно установить**.
   Предупреждение появляется у любого приложения не из Google Play.

Нужен Android 7.0 или новее.

### Вариант 2. Собрать APK в GitHub Actions (без компьютера)

Workflow [`.github/workflows/android.yml`](.github/workflows/android.yml) собирает APK при каждом push.

- **Вручную:** вкладка **Actions → Android APK → Run workflow**. Когда сборка закончится —
  внизу страницы запуска в блоке **Artifacts** будет `12-shagov-apk` (zip, внутри APK).
- **Релизом (удобнее с телефона):** создайте тег `v1.0.0` (например, через **Releases → Draft a new release**,
  новый тег `v1.0.0`) — workflow сам приложит `12-shagov.apk` к релизу.

Репозиторий приватный, поэтому скачивание работает только после входа в GitHub.

### Вариант 3. Собрать у себя

Нужны Node.js 22, JDK 21 и Android SDK (платформа 36).

```bash
npm ci
npm run apk          # → android/app/build/outputs/apk/debug/app-debug.apk
```

Через Android Studio: `npm run sync`, затем открыть папку `android/`.

### Вариант 4. Без APK, как веб-приложение (PWA)

Папка `www/` — обычный статический сайт с офлайн-кэшем. Если разместить её на любом HTTPS-хостинге
и открыть в Chrome на Android, в меню появится **«Установить приложение»** — иконка встанет на рабочий стол.
GitHub Pages для приватного репозитория на бесплатном тарифе недоступны, поэтому основной путь — APK.

Посмотреть в браузере на компьютере: `npm run serve` → <http://localhost:8080>.

## Обновления и подпись — важно, чтобы не потерять записи

Android ставит новую версию поверх старой, только если обе подписаны **одним ключом**.
Без настроек каждая сборка подписывается временным debug-ключом той машины, где собиралась,
и тогда Android скажет «Приложение не установлено» / конфликт подписи. Удаление старой версии стирает записи.

**Перед любым обновлением:** «Ещё → Мои данные → Сохранить резервную копию».
Если обновление не встаёт — удалите приложение, поставьте новое и восстановите копию.

**Чтобы обновления всегда вставали поверх**, один раз создайте постоянный ключ и положите его в секреты репозитория
(**Settings → Secrets and variables → Actions → New repository secret**):

```bash
keytool -genkeypair -keystore shagi.keystore -storetype PKCS12 -alias shagi \
  -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 shagi.keystore   # это значение — в секрет SHAGI_KEYSTORE_BASE64
```

| Секрет | Значение |
|---|---|
| `SHAGI_KEYSTORE_BASE64` | вывод `base64 -w0 shagi.keystore` |
| `SHAGI_KEYSTORE_PASSWORD` | пароль хранилища |
| `SHAGI_KEY_ALIAS` | `shagi` |
| `SHAGI_KEY_PASSWORD` | пароль ключа (у PKCS12 совпадает с паролем хранилища) |

С секретами workflow собирает release-APK, подписанный этим ключом; номер версии растёт с каждой сборкой.
Сам файл ключа в репозиторий не кладите (`*.keystore` в `.gitignore`) и сохраните его копию:
без него обновления поверх установленной версии станут невозможны.
Первый переход с debug-подписи на постоянный ключ потребует одной переустановки — через резервную копию.

## Приватность

- Записи лежат в памяти приложения на телефоне и никуда не отправляются; приложение не делает сетевых запросов.
  Ссылки на источники открываются во внешнем браузере.
- Облачное резервное копирование Android для приложения выключено (`allowBackup="false"`),
  чтобы записи шагов 4–9 не уходили в облако без вашего решения. Переносите данные через резервную копию.
- Файл резервной копии — обычный JSON в открытом виде. Храните его там, куда нет доступа посторонним.
- Отдельного PIN-кода в приложении нет — используйте блокировку экрана телефона.

## Устройство проекта

```
www/                    веб-приложение (без фреймворков и сборки)
  index.html
  css/app.css
  js/content.js         ← все тексты: шаги, критерии, справка, источники
  js/app.js             логика: навигация, сохранение, инструменты шагов
  js/intro.js, css/intro.css, fonts/   вступление
  research.html         генерируется из docs/issledovanie.md
  sw.js, manifest.webmanifest, icons/   для установки как PWA
docs/issledovanie.md    исходное исследование
android/                Android-проект Capacitor 8 (minSdk 24, targetSdk 36)
scripts/
  build-research.mjs    docs/issledovanie.md → www/research.html (npm run research)
  make_icons.py         иконки и заставки (npm run icons, нужен Pillow)
.github/workflows/android.yml   сборка APK в GitHub Actions
```

**Поменять тексты:** правьте `www/js/content.js`. Ссылки на источники пишутся как `[Н4]` —
код должен быть в списке `sources` того же файла.
**Обновить исследование:** замените `docs/issledovanie.md` и выполните `npm run research`.

Записи хранятся в `localStorage` под ключом `twelve-steps:v1`; формат резервной копии —
`{ app, exportedAt, data: { steps, reviews, amends, clean, check } }`.
