# Как загрузить оригиналы в Первый шаг

В приложении: **Шаг 1 → Загрузить материалы в шаг**. Создай или открой Тетрадь
своей парольной фразой. Тексты сохраняются на устройстве в том же зашифрованном
хранилище и становятся доступны после разблокировки. Пересобирать APK не нужно.

## Три места для текстов

| Кнопка | Что добавлять | Где появится |
| --- | --- | --- |
| Добавить книгу | PDF с текстовым слоем, EPUB, TXT или Markdown | Источники → название книги |
| Добавить формулировку | Короткий текст шага, например step.md | Главный экран Первого шага |
| Добавить вопросы | TXT/Markdown с нумерованным списком, например questions.md | Тетрадь → Вопросы из моего пака |

В каждом случае выбери файл, нажми **Прочитать выбранный файл**, проверь предпросмотр
и нажми **Сохранить**. Можно вставить текст вручную в поле предпросмотра.

Для PDF укажи диапазон страниц файла, включая обложку. Номера печатных страниц могут
отличаться. Если в файле только фотографии страниц, сначала нужен распознанный TXT
или Markdown: распознавание сканов в приложение не входит. EPUB читается в порядке
глав; номера его частей не выдаются за номера страниц PDF.

Из подготовленного личного контент-пака подходят:
- `step01/sources/*.md` — в книги;
- `step01/step.md` — в формулировку;
- `step01/questions.md` — в вопросы.

Для предоставленного специального тиража БТ6 раздел Первого шага находится на
PDF-страницах 49–54; в предоставленном Руководстве 2021 — на 2–11. Эти диапазоны
не универсальны для других редакций. Проверь границы фрагмента в предпросмотре.

## Вопросы по темам

Пример формата с текстом-заглушкой:

```markdown
# Отрицание

1. Здесь вопрос из твоего экземпляра.
2. Здесь следующий вопрос.

# Бессилие

1. Здесь вопрос по другой теме.
```

Поддерживаются семь названий тем приложения и идентификаторы addiction, denial,
bottom, powerlessness, unmanageability, reservations, surrender. Каждый вопрос
становится отдельной ссылкой в Тетради. Его можно открыть и написать ответ.
Одинаковые вопросы в той же теме получают устойчивый id: повторная загрузка или
перестановка списка сохраняет привязку ответов. После замены списка прежние ответы
доступны в разделе **Ответы к прежним вопросам**.

## Где лежат данные

- Оригиналы, добавленные владельцем, не записываются в код и не отправляются в GitHub.
- PDF/EPUB разбираются локально; для этого APK содержит PDF.js и fflate, без CDN.
- Лимит файла — 25 МБ, извлечённого текста — 2 миллиона знаков. Для большой книги
  выбирай нужные PDF-страницы. Для формулировки лимит 4000 знаков.
- В хранилище сохраняются извлечённый текст, название и сведения о файле, а не
  исходный бинарный PDF/EPUB. Сам оригинал остаётся в выбранном файле на телефоне.
- Статус издания и опечатки не исправляются автоматически. Проверка текстового слоя
  и переносов остаётся за владельцем; черновик можно отметить в названии источника.
- Парольная фраза и ключ живут только в памяти. Забытый пароль не восстанавливается.
  Как и прежде, Тетрадь пока не включена в общий экспорт приложения.

## Разработка и сборка

```
npm ci
npm run content:steps
npm run test:step
npm run sync
```

`content:steps` сначала копирует локальные библиотеки чтения в `www/vendor/`.
Папки `content-pack/`, `www/vendor/` и сгенерированный `www/js/step-content.js`
исключены из Git. CI собирает APK без личного контент-пака; материалы добавляются
после установки на устройстве. Service Worker кэширует обе библиотеки для офлайн-чтения.

Новая загрузка не добавляет шесть интерактивов, PDF-экспорт Тетради, Keystore или
биометрию — эти пункты полного ТЗ остаются отдельными незавершёнными этапами.

## Проверки

`npm run test:step` — тесты формата вопросов, ссылок, парсера и шифрования.
Дополнительная проверка интерфейса: `python3 tests/material-flow.py` (нужны Python
Playwright и Chromium). Тест использует синтетические PDF/EPUB и проверяет три
места загрузки, сохранение ответов после замены вопросов, перезагрузку и офлайн-импорт.
Для уже запущенного сервера можно указать `STEP_TEST_URL=http://localhost:4185/`.

## Скачивание APK

В ветке `ccr-904d7ed7-auu10m` при недоступном хранилище артефактов Actions
сборка помещает APK в предварительный GitHub Release с тегом `apk-<commit>`.
Доступ к файлу определяется приватностью репозитория; доступ не меняется.
Существующие артефакты и релизы автоматически не удаляются.
