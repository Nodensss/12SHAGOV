# Вступление Первого шага

Эта сцена показывается при настоящем запуске приложения, а не только на экране шага.
Она заменяет старую SVG-фигуру в капюшоне. Существующие записи и настройки вступления сохраняются.

## Сценарий

1. Сущность смотрит на человека и держит закрытую книгу. Сверху остаются звук и пропуск.
2. После касания раскрывается обложка; закрытый кадр сменяется открытой книгой.
3. Камера приближается к тёмному корешку и проходит внутрь. Текст и кнопки остаются неподвижными.
4. Короткие фразы объясняют, что здесь можно честно посмотреть на свой опыт и записать его.
5. Финальная кнопка открывает Первый шаг. Пропуск тоже ведёт туда.

При отключённом движении используются затухания. При сворачивании время сцены приостанавливается.
Звук изначально выключен; явный предыдущий выбор человека сохраняется.

## Файлы

- `www/js/intro.js`: сценарий, управление, аудио, очистка обработчиков и фокуса.
- `www/css/intro.css`: кадрирование, обложка, типографика, адаптация к экрану.
- `www/images/intro-entity-closed.png`, `intro-entity-open.png`: два согласованных кадра, без сети.
- `www/js/app.js`: холодный запуск без прямой ссылки открывает `#/step/1`.
- `www/sw.js`: обе картинки входят в офлайн-кэш PWA; в APK они встроены напрямую.

## Проверка

`python3 tests/intro-flow.py` проверяет реальный запуск с настройками по умолчанию, загрузку
картинок, пропуск, финальный переход и уменьшение движения. Нужны Playwright и Chromium.
Проверки парсеров и личных материалов: `npm run test:step`, `python3 tests/step-bundle-flow.py`.

После `cap sync android` и сборки: `python3 scripts/check-apk-entry.py dist/12-shagov.apk`.
Проверка открывает ZIP APK, сравнивает SHA-256 кода и картинок с текущими файлами и ищет
маркер `cinematic-entity-v1`. Сборка не выдаётся, если внутри оказалась старая заставка.
Это проверка содержимого APK; установка на физический телефон проверяется отдельно.
