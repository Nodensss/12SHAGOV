# Добавление шага в движок

Текущий статус: основа движка чтения. Тетрадь, типы практик и защищённое хранилище
ещё не реализованы. Не использовать эту версию для сохранения личных ответов.

1. Создай `www/assets/steps/step02/step.json` по примеру step01. Укажи id, title,
   семь topics и четыре sections. Текущая проверка тем рассчитана на Шаг 1;
   расширение словаря тем следующего шага ещё предстоит.
2. Добавь авторские главы в `explain/*.md`. Поддерживаются абзацы, заголовки и
   переходы `[[practice:id]]`, `[[journal:topic]]`. Полный Markdown пока не реализован.
3. Личные источники положи в `content-pack/step02/sources/*.md`. Метаданные:
   id, title, section, order, topics. Темы абзацев: `<!-- topic: denial -->`.
4. Формулировка шага берётся из `content-pack/step02/step.md`.
5. Выполни `npm run content:steps`. Полученный `www/js/step-content.js` содержит
   частный текст и исключён из Git. `npm run sync` запускает сборщик автоматически.

Для следующего шага пока нужно подключить маршрут к StepEngine.render. Общий
реестр маршрутов без правки движка входит в незавершённые работы.

Новые исходные тексты литературы в Git добавлять не нужно. Пример в
`content-pack.example/` содержит только заглушки. Импорт с телефона сейчас доступен
для текущего сеанса, без сохранения в незашифрованное хранилище.
