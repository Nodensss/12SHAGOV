# ТЗ модуля 5: шаг «Пятый»

**Продукт:** приложение «12 шагов — свой путь»  
**Тип:** интерактивный модуль единой программы  
**Связанные материалы:** [дословные фрагменты шага 5](/home/ozr/Documents/Codex/2026-10-22/dsx/outputs/Шаг_05_Пятый.txt)  
**Общие требования:** см. [ТЗ приложения](./ТЗ_Приложение_12_Шагов.md).

## Цель модуля

Подготовиться к честному разговору с безопасным человеком

## Вовлекающий элемент

«Репетиция разговора» без отправки сообщений: пользователь выбирает, что готов рассказать, какие темы вызывают тревогу и какие договорённости помогут ему чувствовать себя безопаснее.

## Сценарий пользователя

1) Короткое пояснение роли доверенного слушателя. 2) Личный чек-лист готовности и границ. 3) Подготовка структуры разговора: с чего начать, что трудно произнести, где нужна пауза. 4) Репетиция фраз в приватном черновике. 5) Итоговый список вопросов для обсуждения со спонсором.

## Особые требования и границы

Не назначать собеседника, не отправлять ему текст и не обещать конфиденциальность третьего лица. Пользователь решает, когда и с кем говорить.

## Критерии готовности

Модуль считается готовым, если:

- Пользователь может закончить без выбора контакта; подготовленная речь сохраняется только локально; есть функция очистить все данные сессии; цитаты и пояснения визуально разделены.
- пользователь может поставить паузу, вернуться без потери черновика и пропустить любой вопрос;
- дословная цитата из источника отделена от пояснений приложения и снабжена ссылкой на страницу;
- текст, кнопки и аудио соответствуют общим требованиям доступности и приватности;
- модуль не использует баллы, рейтинги или оценку «правильности» пользователя.
