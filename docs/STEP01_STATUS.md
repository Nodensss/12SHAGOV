# Шаг 1: промежуточный отчёт

## Статус

Это начало этапа 1, не выполнение всех критериев приёмки ТЗ от 10 ноября.

Сделано:
- Сохранён существующий Capacitor/JavaScript-каркас Android.
- Описание четырёх разделов и семи тем в JSON.
- Главный экран Шага 1, свободный переход между разделами, продолжение чтения.
- Парсер Markdown-источников с фронтматтером, разметкой тем и id абзацев.
- Сборщик локального контент-пака; исходники и сгенерированный частный пакет
  исключены из Git. Формулировка читается из step.md.
- Пустой пак объясняет способ добавления материалов. Импорт MD/TXT с устройства
  позволяет читать документ в текущем сеансе, фильтровать источники по теме.
- Размер текста, межстрочный интервал, колонка до 70ch и позиция чтения.
- Безопасное отображение исходного HTML как текста, без выполнения кода.
- Вводная авторская глава, переходы из абзаца к месту будущей записи.
- Доступный в одно касание экран поддержки без встроенных телефонных номеров.

Не реализовано:
- Выделения, пометки, сохранение импортов, семь полноразмерных глав и глоссарий.
- Тетрадь, история ответов, свои вопросы, результаты шести практик.
- Экспорт PDF/TXT, FeedbackProvider, заметки и задания спонсора, итог шага.
- Room/зашифрованная база, Keystore, PIN/биометрия, автоблокировка, FLAG_SECURE,
  исключения облачного бэкапа, нейтральные aliases. INTERNET пока присутствует.
- Токены темы, затухающий дрейф, настройки контактов и вибрации.
- Android-сборка и проверка установки. Приёмка не заявляется.

## Расхождения

Репозиторий уже содержит Capacitor и JavaScript, а не Compose/Room. Переписывание
всего приложения не выполнялось. Для защищённого хранилища нужен нативный плагин
и явная миграция существующего localStorage. Нельзя объявлять его зашифрованной БД.
В других ветках уже есть исходная библиотека; её история не переписывалась и старые
документы не удалялись. Требование отсутствия литературы во всём репозитории ещё
не выполнено.

При перезапуске среды 10 ноября старый /workspace оказался пуст. Проект восстановлен
из удалённой Android-ветки 9603e90. Локальный коммит кинематографической заставки и
сгенерированные изображения из прежней среды отсутствуют. Здесь сохранена SVG-заставка
из GitHub. Нельзя считать прежнюю новую заставку частью этого коммита.

## Проверка

```
npm run content:steps
npm run test:step
python3 -m http.server 4175 --directory www
```

Открой `http://localhost:4175/#/step/1`, пропусти заставку. Проверь четыре карточки,
пустые Источники, импорт собственного MD/TXT, настройку чтения и поддержку.
Импорт живёт только до перезагрузки; заметки и ответы пока не сохраняются.

Пять тестов проверяют фронтматтер, темы, стабильные id абзацев, обработку недопустимых
данных, пустой пак и схему шага. Браузерная проверка включает импорт, защиту от HTML,
четыре раздела и экран поддержки. Проверка Android отсутствует.
