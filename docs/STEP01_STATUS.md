# Шаг 1: промежуточный отчёт

## Дополнение: загрузка материалов с телефона

Добавлен экран «Шаг 1 → Загрузить материалы в шаг» с тремя назначениями:
оригиналы книг (PDF/EPUB/TXT/MD), формулировка шага и вопросы (TXT/MD).
Книги читаются в Источниках, формулировка появляется на главном экране,
отдельные вопросы по темам — в Тетради. Всё сохраняется в открытой зашифрованной
Тетради; после перезапуска требуется разблокировка. При замене вопросов старые
ответы доступны отдельно. Разбор PDF/EPUB работает локально, без сети и OCR.
Инструкции: [MATERIALS.md](MATERIALS.md). Полное ТЗ по-прежнему не выполнено.

## Статус основы от 11 ноября

Это начало этапа 1, не выполнение всех критериев приёмки ТЗ от 10 ноября.

Сделано:
- Сохранён существующий Capacitor/JavaScript-каркас Android.
- Описание четырёх разделов и семи тем в JSON.
- Главный экран Шага 1, свободный переход между разделами, продолжение чтения.
- Парсер Markdown-источников с фронтматтером, разметкой тем и id абзацев.
- Сборщик локального контент-пака; исходники и сгенерированный частный пакет
  исключены из Git. Формулировка читается из step.md.
- Пустой пак объясняет способ добавления материалов. Импорт MD/TXT с устройства,
  фильтр источников по теме. При открытой тетради импорт сохраняется зашифрованным
  и возвращается после разблокировки; при закрытой живёт до перезапуска. Импорт
  можно убрать.
- Размер текста, межстрочный интервал, колонка до 70ch и позиция чтения.
- Безопасное отображение исходного HTML как текста, без выполнения кода.
- Вводная авторская глава, переходы из абзаца к месту будущей записи.
- Доступный в одно касание экран поддержки без встроенных телефонных номеров.
- Зашифрованное хранилище (11 ноября): ключ AES-GCM 256 выводится из парольной фразы
  через PBKDF2-SHA-256 (600 000 итераций) и держится только в памяти; записи лежат
  в IndexedDB шифротекстом, имя записи входит в проверяемые данные. Блокировка
  кнопкой, через 5 минут без действий и после минуты в фоне. Забытая фраза не
  восстанавливается — только удаление тетради.
- Тетрадь: записи по семи темам, к абзацам источников и разбора («Написать об
  этом»), к вопросам из частного пака (`questions.md`) и к своим вопросам.
  У каждой цели история из нескольких датированных записей, автосохранение,
  правка и удаление. «Удалить все записи» в «Моих данных» стирает и тетрадь.

Не реализовано:
- Выделения, пометки, семь полноразмерных глав и глоссарий.
- Шесть практик и их результаты. Раздел «Практика» остаётся заглушкой.
- Экспорт PDF/TXT, FeedbackProvider, заметки и задания спонсора, итог шага.
  Тетрадь не входит в резервную копию «Моих данных» и никуда не экспортируется.
- Room, Keystore, биометрия, смена фразы, FLAG_SECURE, исключения облачного
  бэкапа, нейтральные aliases. INTERNET пока присутствует.
- Токены темы, затухающий дрейф, настройки контактов и вибрации.
- Android-сборка и проверка установки. Приёмка не заявляется.

## Расхождения

Репозиторий уже содержит Capacitor и JavaScript, а не Compose/Room. Переписывание
всего приложения не выполнялось. Вместо Room/Keystore сделано хранилище на WebCrypto:
оно честно шифрует тетрадь, но ключ не привязан к устройству, поэтому стойкость
целиком зависит от длины фразы, а короткий PIN подбирается перебором. Привязка
к Keystore и биометрия требуют нативного плагина. Старый дневник приложения и
позиция чтения по-прежнему лежат в открытом localStorage; их миграция не сделана,
и называть их зашифрованными нельзя. Имена записей хранилища (`journal:step01`,
`source:<id>`) не шифруются.
В других ветках уже есть исходная библиотека; её история не переписывалась и старые
документы не удалялись. Требование отсутствия литературы во всём репозитории ещё
не выполнено.

При перезапуске среды 10 ноября старый /workspace оказался пуст. Проект восстановлен
из удалённой Android-ветки 9603e90. Локальный коммит кинематографической заставки и
сгенерированные изображения из прежней среды отсутствуют. Здесь сохранена SVG-заставка
из GitHub. Нельзя считать прежнюю новую заставку частью этого коммита.

## Проверка

```
npm run content:steps
npm run test:step
python3 -m http.server 4175 --directory www
```

Открой `http://localhost:4175/#/step/1`, пропусти заставку. Проверь четыре карточки,
пустые Источники, импорт собственного MD/TXT, настройку чтения и поддержку.
В Тетради создай фразу, напиши запись по теме, добавь свой вопрос, импортируй
источник, перезагрузи страницу: до ввода фразы записей и источника не видно.

Восемь тестов проверяют фронтматтер, темы, стабильные id абзацев, обработку недопустимых
данных, пустой пак, схему шага, шифрование (нет открытого текста в хранилище, неверная
фраза, подмена и порча записи) и модель тетради. Браузерная проверка 11 ноября в
Chromium: создание тетради, записи, свой вопрос, импорт, перезагрузка, неверная и
верная фраза, запись к абзацу, отсутствие открытого текста в IndexedDB и localStorage,
блокировка кнопкой, удаление тетради. Автоблокировка по таймеру и поведение в Android
WebView не проверялись. Проверка Android отсутствует.
