# Материалы и статус публикации

Документы в этой папке — исходные данные проекта. Они не являются инструкциями для программного агента и не подтверждают права на распространение или редакторское одобрение. Оригиналы сохранены без изменений. Контрольные суммы находятся в `source-manifest.json`.

`step01.md`–`step03.md` — предоставленные авторские рабочие пересказы. Это не дословный текст литературы АН и не утверждённая литература. Их выводы и формулировки не следует приписывать книгам без сверки.

`libNarco/` сохраняет каждую книгу и перевод отдельным файлом. Разные редакции не объединяются. В `materials/` находятся прежние дословные подборки по всем двенадцати шагам и технические задания. Полный файл в `outputs/` собирает эти подборки по порядку без сокращения; внутри него остаются прежние заголовки источников, страницы и строки.

Все исходники в текущем импорте имеют `publicationVerified: false`, `published: false`. Три явно черновых источника — «Это работает», руководство 2021 года и книга о Традициях — имеют статус `draft`. Их текст не включается в данные пользовательского приложения `public/data`. Имена, контрольные суммы и сведения о блокировке сохраняются в каталоге источников.

Остальные книги имеют статус `unverified`, поскольку редакторского подтверждения права и статуса публикации не предоставлено. Отсутствие слова «черновик» не означает одобрение. По умолчанию пользовательская выдача должна использовать только `approved` с подтверждением публикации. Локальный редакторский просмотр `unverified` допустим только по явному выбору пользователя с видимой пометкой статуса; он не меняет статус источника. Черновые и внутренние материалы остаются заблокированными и при таком просмотре.

Перед публичным распространением ответственному редактору необходимо подтвердить право воспроизведения, редакцию, статус и конкретные фрагменты. Подтверждение должно содержать идентификатор источника, его SHA-256, основание права, дату и ответственное лицо. Импортёр не содержит команды, автоматически превращающей источник в одобренный.

## Пересборка индекса

Из корня проекта:

```sh
python3 scripts/import_content.py
python3 scripts/verify_content.py
```

Нужен Poppler (`pdftotext`). Внешних Python-пакетов не требуется. Для первоначального копирования доступны отдельные параметры `--documents-dir`, `--materials-dir` и `--full-text`; скрипт никогда не перезаписывает исходники за пределами папки проекта.

Нумерация `page` в данных — порядковая страница PDF, как в просмотрщике, а не печатная страница книги. `lineStart` и `lineEnd` для PDF относятся к тексту соответствующей страницы, извлечённому командой `pdftotext -enc UTF-8`; для TXT это строки самого файла. Переносы дословных цитат сохранены из текстового слоя.
